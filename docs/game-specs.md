# 九款游戏实现规格

> 先读 `docs/GAME_API.md`，再看 `games/whack/` 作为参考实现。
> 每个游戏只在自己的目录里写文件；`slots.json` 已经占好位，不要改。
> 视觉基线：调色板只用 `P.*`，像素字只用 `drawPixelText`，不允许外部素材。
> 逻辑尺寸宽度统一 168，具体高度见各条目。

---

## 2. snake · 贪吃蛇

- 文件：`games/snake/{package.json,src/meta.ts,src/index.ts,src/art.ts,test/snake.test.ts}`
- `size: { w: 168, h: 168 }`，`scoreMode: "high"`
- HUD：`score`（分数，pad 5）、`length`（长度，2 位）、`best`（最高，5 位，tone time）
- 文案建议：
  - tagline：`吃到 20 颗，别咬到自己`
  - duration：`1–3 分钟`
  - tags：`果实 +10`、`每 5 颗加速`、`撞墙或咬到自己结束`
- 尺寸：16×16 网格，cell 10px，起点 (4,4)；画布四周留 4px 边框（`P.line`）。

**规则**
- 初始长度 3，向右移动，每 `tickMs` 走一格（初值 150ms，每吃 5 颗减 8ms，最低 70ms）。
- 吃果实：+10 分，长度 +1，刷新果实到空格（不在蛇身上）。
- 撞墙 / 咬到自己 → `ctx.end({ score, title: "撞到了", kicker: "GAME OVER", stats: [{label:"最长长度", value}, {label:"吃到果实", value}] })`。
- 暂停时不要累积方向队列。

**输入**
- 方向键 / WASD；滑动（`ctx.input.swipe.onSwipe`）四个方向；`1–4` 可选映射（left/up/right/down）。
- 转向队列最多缓存 2 个，禁止 180° 反向。

**实现要点**
- 逻辑移动用固定步进累加器（`acc += dt; while (acc >= tickMs) step()`），移动插值用于绘制（`t = acc/tickMs`）让蛇平滑滑动，但判定用格点。
- 蛇身用 `P.mint` 头 + `P.grassHi` 身 + `P.grass` 尾，眼睛 1px 白点；果实画成 3px 红/金像素苹果。
- 画布外框、网格淡纹（`P.line`）用静态图层缓存。
- `start()` 重置蛇、分数、速度、方向队列。

## 3. breakout · 打砖块

- 文件：`games/breakout/*`
- `size: { w: 168, h: 210 }`，`scoreMode: "high"`，`spaceAction: "action"`
- HUD：`score`（分数）、`lives`（生命，2 位）、`level`（关卡，2 位，tone combo）
- 文案：tagline `三块砖一条命，撑到第三关`；duration `2–4 分钟`
- tags：`砖块 10/20/30`、`掉落道具`、`3 条命`

**规则**
- 场地：顶部留 20px 放 HUD 之外的空白，砖区 8 列 × 5 行，砖 18×8，间距 2，左右边距 6。
- 挡板 28×4，y=196；球半径 1.5px（画 3px 方块），初速 120 px/s。
- 反弹角随击中挡板的位置变化（-60°..+60°），球速每关 +12%。
- 砖块分值按行：顶行 30，中间 20，底行 10。命中 1 次即碎（不做多血量）。
- 掉落道具（每 6 块砖随机一个，20% 概率）：加长挡板（8 秒）、三球（分裂成 3 个）、+1 命。道具用 7×7 像素图标，落下 60px/s。
- 清空所有砖 → 下一关（最多 3 关，关卡图案逐步变难：满盘 / 棋盘 / 金字塔）。
- 球掉底 → 生命 -1，回到待发射状态；生命 0 → 结算。
- 3 关全清 → `title: "通关"`，`kicker: "CLEAR"`。
- stats：`关卡`、`剩余生命`。

**输入**
- 鼠标/触屏在画布上移动即挡板跟随（x 映射到 6..162-28）。
- 方向键左右移动（220px/s）；空格或点击发射球（`action` / click）。
- 触屏点一下也能发射。

**实现要点**
- AABB 碰撞，先按 x/y 轴分开计算避免穿透（球速最大 240px/s，dt 上限 50ms，单帧位移 12px < 砖高 8? 会穿透 → 用子步进 `steps = ceil(speed*dt/1000 / 4)`）。
- 粒子：砖块碎裂 4–6 个像素点，颜色取砖色。
- 遮罩：球出界时屏幕轻微震动（`Math.sin` 偏移 2px）。

## 4. invaders · 像素入侵者

- `size: { w: 168, h: 210 }`，`scoreMode: "high"`
- HUD：`score`、`wave`（波次，2 位）、`lives`（生命，2 位）
- 文案：tagline `五波敌机，守住最后一行`；duration `2–4 分钟`
- tags：`敌机 10/20/30`、`每波加速`、`3 条命`

**规则**
- 玩家飞船 11×7，位于底部 y=194，可左右移动（键盘 120px/s，触屏拖拽直接跟随）。
- 自动射击：每 340ms 一颗子弹（向上 260px/s），伤害 1；键盘/触屏不需要按射击。
- 敌阵：4 行 × 6 列，起始 y=30，整体左右移动，碰到边界下压 8px，速度每波 +15%。
- 敌机分值按行 30/20/20/10；每波清空后 +50 波次奖励。
- 敌机随机向下投弹（间隔从 1.2s 递减到 0.5s），子弹 180px/s，命中玩家 -1 命。
- 玩家被击中 → 短暂无敌 1.2s（闪烁），生命 0 → 结算。
- 5 波全清 → `title: "守住了"`, `kicker: "CLEAR"`。
- stats：`波次`、`命中率`。

**实现要点**
- 实体数组（敌机、子弹、敌弹、粒子），用对象池（复用数组 + `alive` 标记），不要每帧 new。
- 敌机用 3 种精灵（不同颜色 `P.lav` / `P.mint` / `P.amber`），图案 11×7 像素。
- 星空背景：80 颗静态星，两层不同速度缓慢下移。

## 5. blocks · 俄罗斯方块

- `size: { w: 200, h: 392 }`（左侧 10×20 棋盘 + 右侧 NEXT 栏 + 底部 44px 触屏按键区），`scoreMode: "high"`，`spaceAction: "action"`
- HUD：`score`、`lines`（消行，3 位）、`level`（等级，2 位）
- 文案：tagline `十行一级，堆到顶就结束`；duration `3–8 分钟`
- tags：`消行 100/300/500/800`、`每 10 行升级`、`硬降 +2/格`

**规则**
- 10 列 × 20 行，cell 16px；棋盘起点 (4, 8)，底部留 8px。
- 7 种方块（I O T S Z J L），7-bag 随机；初始下落 800ms/格，每级 -60ms，最低 120ms。
- 操作：左右移动、下软降（20ms/格 +1 分）、上/X 旋转（顺时针，带简单踢墙：左右各试 1 格）、空格硬降（+2 分/格）。
- 消行：1/2/3/4 行 = 100/300/500/800 × 等级；每 10 行升 1 级。
- 生成位置被占用 → 结算，`title: "堆到顶了"`。
- 右侧显示 next（下一个方块 4×4 区域）；ghost 用 20% 透明度的轮廓。
- stats：`消行`、`等级`。
- 触屏：底部 60px 画 4 个按钮（左 / 右 / 旋转 / 硬降），点击判定按矩形；键盘同样可用。按钮区域不参与棋盘绘制。

**实现要点**
- 旋转用矩阵坐标变换 `(x,y) -> (y, -x)`，每种方块 4 个旋转态，预先算好，运行时不重新分配。
- 锁延迟 500ms：落地后仍可左右/旋转，超时才锁定；锁定后检查消行（带 120ms 闪烁动画，动画期间不接受新方块）。
- 绘制用 `bevel()` 给每个格子高光/暗边，配色从 `P` 里取 7 种。

## 6. merge · 2048

- `size: { w: 168, h: 168 }`，`scoreMode: "high"`
- HUD：`score`（pad 5）、`moves`（步数，4 位）、`bestTile`（最大块，4 位，tone combo）
- 文案：tagline `滑到 2048，别把格子堵死`；duration `3–10 分钟`
- tags：`合并得分`、`一步一存档`、`无路可走结束`

**规则**
- 4×4 棋盘，cell 38，间距 3，起点 8；初始 2 个随机块（90% 是 2，10% 是 4）。
- 滑动合并：同值合并一次，得分 += 合并后的值；每次有效移动后生成一个新块。
- 无可移动（没有空格且相邻无同值）→ 结算。
- 达到 2048 不结束，可以继续冲更高分；`title: "没有空格了"`。
- stats：`最大方块`、`步数`。
- 支持一步撤销（`x` / `secondary`），撤销后不生成新块，且撤销只能一次。

**实现要点**
- 逻辑与动画分离：棋盘是数字矩阵；动画用「每块从旧坐标插值到新坐标」的列表，120ms，`easeOutCubic`。
- 方块颜色按数值查表（2 用 `P.panel2`，4 用 `P.line`，8 用 `P.amber`，16 用 `P.orange`，32 用 `P.red`，64 用 `P.redDeep`，128+ 用 `P.gold`/`P.mint` 交替），数字用 `drawPixelText`，超过 4 位自动缩小字号。
- 滑动阈值 22px；键盘方向键/WASD。

## 7. memory · 记忆翻牌

- `size: { w: 168, h: 168 }`，`scoreMode: "low"`（用时越少越好），`scoreLabel: "用时（秒）"`，`bestLabel: "最快纪录"`
- HUD：`time`（时间，kind time，tone time）、`moves`（步数，4 位）、`pairs`（已配对，2 位）
- 文案：tagline `16 张牌，8 对图案`；duration `30 秒–2 分钟`
- tags：`配对成功 +1`、`翻错扣步`、`用时越短越好`

**规则**
- 4×4 共 16 张牌，8 对图案；图案用 8 个自绘的 16×16 像素图标（星星、心、蘑菇、剑、盾、药水、钥匙、炸弹），颜色都从 `P` 取。
- 点击翻开，翻错（两张不同）停顿 550ms 后盖回；翻对保持翻开并 +1 对。
- 计时从第一次点击开始；全部配对 → `ctx.end({ score: 用时秒数, ... })`，stats：`步数`、`正确率`（正确翻牌次数 / 总翻牌次数）。
- 超过 999 秒上限保护（不会发生，但 score 别溢出）。

**实现要点**
- 牌面翻动用宽度缩放（`scaleX: 1 -> 0 -> 1`）+ 背面/正面切换，160ms。
- 背面统一用 `P.panel` + 像素问号；正面用 `P.cream` 底 + 图案。
- 键盘：方向键移动光标 + Enter 翻牌（可选，触屏优先）。
- `start()` 重新洗牌（`shuffle`）。

## 8. dodge · 陨石雨

- `size: { w: 168, h: 210 }`，`scoreMode: "high"`
- HUD：`time`（剩余时间，kind time）、`score`、`shield`（护盾数量，2 位，tone mint）
- 文案：tagline `撑过 45 秒，别被砸中`；duration `45 秒一局`
- tags：`存活 +2/秒`、`擦身 +15`、`护盾挡一次`

**规则**
- 玩家 9×9 飞船，跟随指针/方向键移动（限制在场地内），拖影 2 帧。
- 陨石从顶部随机 x 落下，速度 60→160 px/s 随时间提升，尺寸 5–11px，带旋转像素纹理。
- 命中判定：圆-矩形近似；被击中时若有护盾则消耗护盾并震屏，否则结束。
- 擦身判定：陨石边缘距离飞船 < 6px 且未命中 → +15 分，短暂粒子。
- 每 9 秒掉落一个护盾道具（上限 3）。
- 存活 45 秒 → `title: "活下来了"`，`kicker: "SURVIVED"`。
- 得分：每 100ms 存活 +2（45 秒共 900），擦身 +15，护盾未用每个 +30。
- stats：`存活时间`、`擦身次数`。

**实现要点**
- 对象池：陨石最多 60 个；粒子最多 120 个；全部近似圆形碰撞。
- 屏幕震动：命中/擦身时 `shake` 衰减，渲染时整体位移。
- 背景星空缓慢下移，底部一条地平线光带（`P.lineHi`）。

## 9. tiles · 别踩白块

- `size: { w: 168, h: 252 }`，`scoreMode: "high"`
- HUD：`score`、`combo`（连击，3 位，tone combo，suffix "×1"）、`speed`（速度等级，2 位）
- 文案：tagline `四轨往下砸，踩错就结束`；duration `30–90 秒`
- tags：`每块 +10 ×连击`、`每 10 块加速`、`踩空即结束`

**规则**
- 4 条轨道，每条 42px 宽，起点 x=0，画布高 252；顶部 12px 为判定区。
- 方块从顶部下落，速度 90px/s 起，每 10 块 +12px/s（上限 300）。
- 玩家点击/按键 1–4 命中对应轨道的**最下方**方块：+10 × 连击倍率（1 + floor(combo/10)，最高 5），连击 +1，方块消失。
- 点空（该轨道没有可点方块）或方块越过底部判定线 → 结束。
- 同时最多 3 个方块；生成间隔随速度缩短（`max(0.22, 0.6 - speed*0.01)` 秒）。
- `spaceAction: "action"` 可选：空格命中当前最下方方块所在轨道（便于单手）。
- stats：`最高连击`、`命中块数`。

**实现要点**
- 判定窗口：方块底部进入画布底部往上 56px 的区域才能被点中（避免点太早）。
- 方块颜色按轨道：`P.cream` / `P.amber` / `P.mint` / `P.lav`，命中时闪白 + 粒子。
- 轨道分隔线用 `P.line`，底部判定线用 `P.lineHi` + 像素刻度。

## 10. mines · 像素扫雷

- `size: { w: 168, h: 168 }`，`scoreMode: "low"`（用时越少越好），`scoreLabel: "用时（秒）"`，`bestLabel: "最快纪录"`
- HUD：`time`、`flags`（剩余雷数，2 位）、`opened`（已开格，3 位）
- 文案：tagline `8×8 十颗雷，第一下不会炸`；duration `1–5 分钟`
- tags：`长按插旗`、`首点安全`、`清完即通关`

**规则**
- 8×8，10 雷，cell 19px，起点 8，间距 1。
- 首次点击保证安全：先点击再布雷，排除该格及其 8 邻域。
- 左键/轻点翻开；长按 350ms 或右键/`x` 插旗；再次长按取消。
- 翻开空白格 → 洪水填充（BFS，展开 0 邻域）。
- 踩雷 → `title: "踩到雷了"`，stats：`已开格`、`用时`；`score` 仍是用时秒数。
- 翻开所有非雷格 → `title: "扫雷完成"`，`kicker: "CLEAR"`。
- 插旗数量不超过 10；旗子用 `P.red` 小三角，未开格用 `P.panel2` 底 + `bevel()`。
- 数字 1–8 分别用 `P.mint / P.gold / P.orange / P.red / P.lav / P.pink / P.cream / P.white`。

**实现要点**
- 长按实现：`pointer.down` 记录时间与格子，`pointer.up` 时若 `elapsed > 350ms` 且未移动超过 8px → 插旗，否则翻开。触屏 contextmenu 已经被壳层拦掉，自己再 `preventDefault`。
- 第一次点击前不布雷；布雷后再计算邻雷数。
- `opened` 计数用于胜利判定，不要每次遍历。

## 完成后自检

```bash
npx tsc -p tsconfig.json --noEmit        # 只看自己目录的报错
npx vitest run games/<id>               # 有单测就跑到绿
```

然后向调度方汇报：新增文件列表、玩法要点、已知限制、单测结果。
不要运行 `vite build`（会和其他并行任务抢 `dist/`）。
